# Visual Node Flow / Görsel üretim akışı

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/visual-node-flow/).

Komut, tohum, örnekleme ve çıktı düğümlerinden geçen bir işin simülasyonu.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Düğüm 1
- Düğüm 2
- Düğüm 3
- Düğüm 4
- Adım süresi (s)

Akış dört adımlı bir çizim olarak oynatılır. Düğüm adlarını ve gecikmeyi değiştirip kendi süreç diyagramını oluşturabilirsin.

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Name four steps and set their timing to build an animated process diagram.

Open [the live tool](https://omerbek.github.io/visual-node-flow/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
